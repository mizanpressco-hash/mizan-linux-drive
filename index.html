Personal desktop integration

Mizan Linux Drive

A personal Google Drive connection for the owner's Linux workstation, powered by rclone.

What it does

The integration makes the account owner's Google Drive files available on demand on their Linux computer. It supports browsing, reading, creating, editing, and deleting Drive files when the owner or their authorized local tools perform those operations.

Working Git repositories and builds remain on the local Linux filesystem. Publishing files to Drive and pushing code to GitHub are separate operations chosen by the owner.

Personal use

This is not a public hosted file service. This website explains the integration; it does not sign users in, collect Google data, or provide access to any Drive files.
