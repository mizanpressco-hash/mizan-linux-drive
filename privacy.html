Mizan Linux Drive

Privacy policy

Effective October 25, 2026

This policy covers the personal Mizan Linux Drive integration running on its owner's Linux workstation. It does not describe other Mizan projects or services.

Google account access

The integration uses rclone and Google's OAuth authorization flow. The requested Google Drive permission allows viewing, creating, editing, and deleting files across the authorized Drive account. Google asks the owner to consent before access is granted. The integration does not collect the owner's Google password.

How information is used

Drive metadata is used to list folders and files. File contents are transferred when the owner or authorized local software reads, creates, or changes files. This enables on-demand Drive access and owner-directed file publishing. The setup does not automatically publish the owner's entire Drive or push its contents to GitHub.

Local storage

OAuth credentials are stored in the owner's rclone configuration on the Linux workstation. Files opened or changed through the mount may be cached on that computer, including while changes await upload. Cache cleanup is managed by rclone; open files and pending uploads can remain cached. Software running with the owner's local account permissions can access the mounted files and local configuration.

Sharing and other services

The integration communicates directly with Google Drive. It does not operate a separate developer-hosted file-processing server, sell Google data, or use Google data for advertising. The owner can separately choose to use files with GitHub, coding assistants, or other tools; those actions are governed by the owner's instructions and the respective services' policies. This policy does not change those services' practices.

This website

This informational website has no sign-in form, advertising, or analytics added by this application. Its hosting provider may process ordinary web request information under its own policies. No Google Drive files or OAuth credentials are published on this website.

Stopping access

The owner can stop or unmount the local Drive connection and revoke Mizan Linux Drive access through their Google Account's third-party connections settings. Local cached files and configuration can be removed separately by the owner. Revoking access does not delete the owner's files from Google Drive.
